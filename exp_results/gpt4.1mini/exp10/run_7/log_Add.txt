**Explanation:**  
The previous attempts failed because the loop invariant for the negative `y` case was not true before entering the loop. The key is to express the invariant in terms of the initial value of `n` and how it changes during the loop.

- Initially, `n = -y` (which is positive or zero).
- At any point in the loop, `sum` equals `x` minus the number of decrements performed so far.
- The number of decrements performed so far is `(-y - n)` because `n` decreases from `-y` down to 0.

Hence, the correct loop invariant is:  
`sum == x - (-y - n)`

This is equivalent to:  
`sum == x - (-y) + n`  
which simplifies to:  
`sum == x + y + n`

But since `n` decreases from `-y` to 0, this expression correctly relates `sum` and `n` at every iteration.

This invariant holds before the loop starts (when `n == -y`), because then:  
`sum == x - (-y - (-y)) == x - 0 == x` which matches the initial assignment.
