At loop entry in the `else` branch:

- `n = -y` (since `y <= 0`), so `n >= 0`.
- `sum = x`.

We want an invariant `sum == x - (-y - n)` to hold at loop entry (`n = -y`):

- At loop entry: `sum == x - (-y - n) == x - (-y - (-y)) == x - 0 == x`, which matches the initial `sum`.

But the prover struggles with the expression `x - (-y - n)` because of the subtraction of a subtraction.

To help the prover, rewrite the invariant equivalently as:

`sum == x - (-y) + n`

- `sum == x`
- `x - (-y) + n == x + y + n`

Since `n = -y`, `x + y + n = x + y + (-y) = x`

So the rewritten invariant holds at loop entry.

Inside the loop, each iteration decreases `n` by 1 and subtracts 1 from `sum`, so the invariant holds.

Hence, the invariant:

