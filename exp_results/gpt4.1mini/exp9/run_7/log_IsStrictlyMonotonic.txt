- Change the invariant `0 <= i <= n - 1` to `0 <= i <= n - 1` only when `n >= 1`, else `i == 0`. But since JML does not allow conditional invariants easily, a simpler and sound approach is to allow `i` up to `n - 1` but also allow `i == 0` before the loop.
