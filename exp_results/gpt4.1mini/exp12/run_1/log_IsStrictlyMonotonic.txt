**Explanation:**

The error `LoopInvariantBeforeLoop` means the prover cannot verify that the loop invariant holds before the first iteration, i.e., at the loop entry point.

The problematic invariant is:

```java
//@ maintaining 0 <= i && i <= n - 1;
```

When `i = 0` at loop start, this requires `0 <= 0 && 0 <= n - 1`. But if `n == 0` or `n == 1`, then `n - 1` is `-1` or `0`, so `0 <= n - 1` may be false.

The original loop is:

```java
for (int i = 0; i < n - 1; ++i) {
    ...
}
```

If `n < 2`, the loop body does not execute at all.

- Also, the loop variable `i` ranges from `0` up to but not including `n - 1`, so `i <= n - 1` is the loop condition, but the invariant can be relaxed to `i <= n` to avoid the error.

- Alternatively, specify the invariant as `0 <= i && i <= n` and adjust the rest accordingly.
