- Initially, `n == -y`.
- We want the invariant to relate `sum` to `x` and the progress in `n`.

- But since `n` starts at `-y` and decreases to 0, this does **not** hold initially (because `sum == x` at the start).
  
To fix this, rewrite the invariant as:

```
sum == x - ( (-y) - n )
```

which is equivalent to:

```
sum == x - (initial_n - current_n)
```

At loop start, `n == initial_n`, so `sum == x - 0 == x`, which matches the initial assignment.

This is exactly the expression used above, so the prover should accept it now.
